WooCommerce dashboard analytics widget showing orders, revenue, refunds, customers, and key store health metrics.

== Description ==

Store Insights for WooCommerce adds an analytics widget to your WordPress dashboard, giving you instant visibility into how your store is performing.

The widget displays key WooCommerce metrics such as daily sales, revenue trends, refunds, customer growth, and operational signals, all calculated using native WooCommerce data.

No setup required. Just install, activate, and view your store insights every time you open the dashboard.

Perfect for store owners, managers, and agencies who want fast, actionable insights.

== Key Features ==

- 📊 **Dashboard analytics widget**: View your store performance directly on the WordPress dashboard.
- 🔄 **Automatic refresh with smart caching**: Data refreshes automatically on dashboard view with a lightweight 10-minute cache.
- 💰 **Sales & revenue insights**: Orders, revenue, refunds, and average order value for today and the last 7 days.
- 📈 **Performance & health signals**: Revenue trends, refund rate, and operational indicators to quickly spot issues.
- 🛒 **Best performers overview**: Best-selling products, top categories, and most used coupons.
- 🔐 **Secure & lightweight**: Uses native WooCommerce queries. No external APIs, no data leaves your site.

== Installation ==

= Automatic Install =

1. Log into your WordPress dashboard and go to Plugins &rarr; Add New
2. Search for "Store Insights for WooCommerce"
3. Click "Install Now" under the "Store Insights for WooCommerce" plugin
4. Click "Activate Now"

= Manual Install =

1. Download the plugin from the download button on this page
2. Unzip the file, and upload the resulting `store-insights-for-woocommerce` folder to your `/wp-content/plugins` directory
3. Log into your WordPress dashboard and go to Plugins
4. Click "Activate" under the "Store Insights for WooCommerce" plugin

== Frequently Asked Questions ==

= Does this plugin use external services or APIs? =
No. All data is calculated locally using WooCommerce data. Nothing is sent outside your site.

= Does this affect store performance? =
No. The plugin uses optimized WooCommerce queries and caches results for 10 minutes to avoid unnecessary load.

= Can I manually refresh the data? =
Data refreshes automatically when you view the dashboard after the cache expires. No manual action is required.

= Is this plugin free? =
Yes. Store Insights for WooCommerce is completely free.
